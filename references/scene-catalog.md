# 场景脚手架总览

完整研究文档可以由你在私有环境中自行维护。

这里保留 skill 运行时最常用的场景索引。

## 核心场景

| 场景 | 适合输出 | 推荐 prompt 结构 | 是否优先支持 |
| --- | --- | --- | --- |
| 信息图 / 百科图 | 竖版图、长图、知识卡 | 结构化模块 prompt | 是 |
| PPT 封面图 / 章节头图 | 封面、章节视觉 | 主视觉 + 留白区 + 品牌气质 | 是 |
| PPT 内容配图 | 对比页、流程页、方案页 | 主体 + 图解区 + 文案标签 | 是 |
| 海报 / Banner / 主图 | 电商、活动、品牌视觉 | 标题文案 + 主体 + 卖点区 | 是 |
| UI 设计图 | App 页面、设计系统、游戏界面 | JSON prompt | 是 |
| 漫画 / 分镜 | 多格漫画、剧情页 | 角色 bible + 分镜表 | 是 |
| 角色设定 / 游戏概念 | 角色卡、关系图、世界观图 | 系列一致性 prompt | 是 |
| 参考图编辑 | 风格化、衍生、局部改图 | 保留项 + 修改项 | 是 |
| 长图 / 导览图 | 教程长图、路线图、说明长图 | 分章节模块 prompt | 次优先 |
| 品牌视觉套件 | KV、封面组、海报组 | 素材包 prompt | 次优先 |
| 文章配图包 | 头图、章节图、尾图 | 系列图 prompt | 次优先 |
| 虚拟空间 / 360 概念 | 空间图组、区域图 | 世界观 + 区域功能 prompt | 次优先 |

## 默认 prompt 槽位

```text
goal:
output_type:
subject:
facts:
layout:
text_blocks:
style:
camera_or_view:
consistency:
edit_rules:
negative_constraints:
```

## 快速选型

### 用户说“做 PPT”

先产出：

- 封面图
- 章节图
- 内容页配图

然后如果需要真正 `.pptx` 成品，再接 `$pptx`。

### 用户说“做漫画”

先产出：

- 角色卡
- 风格卡
- 试制分镜页

### 用户说“做 UI”

优先用 JSON prompt，不要只写美术风格。

### 用户说“改图”

优先写：

- 保留什么
- 修改什么
- 只动哪些区域

## 风险提醒

不把下列内容做成默认模板：

- 假证件
- 假票据
- 冒充真实人物或真实平台的伪造截图
